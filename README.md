# מבט שבועי תחרותי — מוקאפ

**זהו מוקאפ להדגמה, לא מוצר ולא פרסום רשמי.** הוא נבנה כדי להמחיש פורמט של סקירת שוק תחרותית שבועית לענף הביטוח והפיננסים בישראל.

## מה יש כאן

| קובץ | מה זה |
|------|-------|
| `index.html` | הדשבורד. רספונסיבי — עמודה אחת במובייל, פריסת web מלאה מ-1024px. כולל מצב ״נגן״ (סטוריז עם התקדמות אוטומטית) |
| `email.html` | גרסת מייל: טבלאות ו-inline styles בלבד, בלי JS |
| `assets/` | לוגו ופונט המותג |

## תוכן

חלון הסריקה: **10–16 באוגוסט 2026**. כל פריט מתויג לנדבך אסטרטגי, ומוצג עם מקור ותאריך פרסום.

ארבעה מתוך ששת הפריטים אומתו מול הכתבה עצמה — תאריך פרסום ולינק ישיר. פריט שלא אומת מסומן בקו מקווקו תחת התאריך, וההרחבה שלו אומרת זאת במפורש. **אין בבריף פרשנות או המלצות — עובדות והקשר עובדתי בלבד.**

## הרצה מקומית

לפתוח את `index.html` בדפדפן. הקובץ עצמאי; צריך רק שתיקיית `assets/` תהיה לידו.

## נגישות ומקלדת

`Esc` סוגר את הנגן · חץ שמאל — הפריט הבא · חץ ימין — הקודם · רווח — השהיה.
